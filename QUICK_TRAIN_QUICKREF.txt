## Requirements

- **Folder:** Contains `.xlsx` or `.xlsm` files
- **Sheet:** All files must have sheet named `Clean Data`
- **Data:** Each file has `iWOW`, `_time`, and flight parameters

## Quick Fixes

**Issue:** No files found
**Fix:** Check folder path is correct

**Issue:** Sheet not found  
**Fix:** Change `SHEET_NAME` in script to match your sheets

**Issue:** Want to start fresh
**Fix:** Delete `flight_data/*.joblib` and `flight_data/*.parquet` first
