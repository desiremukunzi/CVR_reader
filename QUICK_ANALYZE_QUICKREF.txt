# 🚀 QUICK ANALYZE - ONE-PAGE GUIDE

## Setup (Do Once)

**Edit `quick_analyze.py` lines 28-34:**
```python
FLIGHT_FILE_PATH = r'YOUR\PATH\TO\FLIGHT.xlsm'
SHEET_NAME = 'Clean Data'
ADD_TO_TRAINING = False  # False = just analyze, True = add to database
AUTO_OPEN_BROWSER = True
```

## Run Analysis

```bash
cd A:\CVR_reader
python quick_analyze.py
```

## Configuration

### Just Analyze (Default)
```python
ADD_TO_TRAINING = False
```
Quick check, don't modify training database

### Analyze + Add to Training
```python
ADD_TO_TRAINING = True
```
Analyze + add to database + retrain models

## Requirements

**Must have trained models first:**
```bash
python quick_train.py  # Run once to create models
```

**Excel file must have:**
- Sheet named `Clean Data`
- Flight parameters (Fcp, Xcpl, PITCH, etc.)
- `iWOW` and `_time` columns

## Common Issues

**"No trained models found"**
→ Run `python quick_train.py` first

**"File does not exist"**
→ Check file path is correct, use `r'...'`

**"Sheet not found"**  
→ Change `SHEET_NAME` to match your sheet

**Report doesn't open**
→ Check `reports/` folder, open manually
